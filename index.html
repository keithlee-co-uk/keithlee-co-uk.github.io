Personal Hermes Agent

Privacy Policy. Last updated 26 November 2026.

Personal Hermes Agent is a private, single-user automation tool operated by Keith Lee for his own personal use. It is not a commercial product, is not distributed, and is not offered to the public. This page explains what Google account data the tool accesses, why, and how it is handled.

What data is accessed

With the account owner's explicit consent, the tool uses Google OAuth to access:

  • Gmail (read, send, and modify) to organise the owner's own mailbox, archive or delete unwanted mail, unsubscribe from marketing lists, and send the owner failure notifications about his own automation.
  • Google Calendar to read and create reminders in the owner's own calendars.
  • Google Sheets to read and update the owner's own personal records.
  • Google Drive (read-only) to report on the owner's own storage usage. No file contents are modified or deleted through this scope.

Who the data belongs to and who can access it

The data belongs to the account owner. The tool accesses only the Google account that granted consent, and only the account owner can access the tool or its locally stored data. It is not available to other people.

How data is used

Data is used exclusively to perform tasks for the account owner: organising his mailbox, maintaining his calendar reminders and personal records, and reporting storage usage back to him. Messages are processed to determine whether they are wanted and are then filed, archived, or deleted according to rules the owner has set.

Sharing and third parties

No data is shared, sold, or rented. No data is transferred to any third party, no advertising is involved, and no Google user data is used to train or improve machine learning models. Data is used only for the purposes described above.

Storage and retention

The tool runs on the owner's own computer and all retained data uses local-only storage. Email content is not stored on any external server and is not retained beyond the processing needed to complete the task. The only Google credential retained is an OAuth token stored locally on the owner's machine so the automation can run without repeated sign-in.

Security

Access tokens are stored locally with restricted file permissions on the owner's own machine. There is no central server, no database, and no cloud storage of user data. Access can be revoked at any time by the account owner.

Revoking access

The account owner can revoke this application's access at any time at myaccount.google.com/permissions. Revoking access immediately prevents any further use of Google account data.

Google API Services User Data Policy

Personal Hermes Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
